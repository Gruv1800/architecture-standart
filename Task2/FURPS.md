| Код    | Требования                                                                                                          | Комментарий  |
|--------|---------------------------------------------------------------------------------------------------------------------|--------------|
| **F**  | **Функциональные (Functionality)**                                                                                  |              |
| F1     | Клиент может просматривать список доступных депозитов с актуальными ставками на сайте.                              |              |
| F2     | Клиент может просматривать список доступных депозитов с актуальными и персонализированными ставками в интернет-банке. |              |
| F3     | Подача заявки на отрытие депозита с указанием ФИО и номера телефона на сайте.                                       |              |
| F4     | Подача заявки на отрытие депозита с указанием номера счета и суммы депозита в интернет-банке.                       |              |
| F5     | Менеджер осуществляет звонок, а клиент принимает его, для уточнения ставок и подтверждения при подаче заявки на сайте. |              |
| F6     | Подтверждение заявки по СМС на открытие депозита при подаче заявки в интернет-банке.                                |              |
| F7     | Отправка клиенту СМС уведомления о подтверждении ставки и открытии депозита.                                        |              |
| F8     | Заведение новых (редактирование существующих) ставок в XLS и\или АБС.                                               |              |
| F9     | Подтверждение заявок на депозиты в АБС.                                                                             |              |
| **U**  | **Удобство использования (Usability)**                                                                              |              |
| U1     | Максимально удобный UX для клиентов (быстрые отклики, привычный дизайн).                                            |              |
| U2     | Соблюдение корпоративного стиля (цвета, брендинг).                                                                  |              |
| **R**  | **Надёжность (Reliability)**                                                                                        |              |
| R1     | Доступность 99,9% для всех сервисов (интернет-банк, АБС, кол-центр)                                                 |              |
| R2     | Поддержка работы 24/7.                                                                                              |              |
| R3     | Возможность переключения на резервный ЦОД при сбоях.                                                                |              |
| R4     | Горизонтальное масштабирование интернет-банка.                                                                      |              |
| R5     | Вертикальное масштабирование АБС (из-за ограничений БД).                                                            |              |
| **P**  | **Производительность (Performance)**                                                                                |              |
| P1     | Равномерное распределение запросов между серверами и ЦОД.                                                           |              |
| P2     | Избежание перегрузки АБС (минимизация прямых запросов от интернет-банка).                                           |              |
| P3     | Ускорение загрузки справочных данных (исключить задержки >1 сек).                                                   |              |
| **S**  | **Поддерживаемость (Supportability)**                                                                               |              |
| S1     | Использование существующих БД (MS SQL, Oracle).                                                                     |              |
| S2     | Предпочтение технологий, в которых есть внутренняя экспертиза (знакомые языки программирования).                                                                                                                   |              |
| S3     | Совместимость с текущими платформами разработки.                                                                                                                    |              |
| S4     | Постепенный переход на микросервисы (в рамках задачи открытия депозитов).                                                                                                                 |              |
| S5     | Документирование системы для будущего расширения.                                                                                                                  |              |
| S6     | Поддержка Kafka для асинхронной обработки сообщений.                                                                                                                  |              |
| **+R** | **+ Ограничения (Restricitions)**                                                                                   |              |
| +R1    | Шифрование трафика при передаче данных (сайт, интернет-банк).                                                                                                                |              |
| +R2    | Защита персональных данных клиентов.                                                                                                                |              |
| +R3    | Минимизация доработок со стороны подрядчиков.                                                                                                                |              |
| +R4    | Использование внутренних ресурсов банка для реализации бизнес-функционала.                                                                                                            |              |
